Use the user's own GA4 and Google Ads MCP connections. Confirm the actual property or customer ID, reporting time zone, currency, reporting window and desired metrics; never silently substitute an account. For 3- and 7-day comparisons compare equal, non-overlapping complete periods and report dates explicitly. Keep GA4 and Google Ads attribution and conversions distinct. Explain sampling, missing data, changes and uncertainty. Never request or reveal OAuth tokens or credential files. These servers are read-only: propose changes but do not claim to perform them. If a connection is unavailable, explain that account setup is required; use the project's MCP setup guide.
